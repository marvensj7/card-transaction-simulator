# Credit Circuit working scope

The [submission proposal](03_Submission_Proposal.md) is the complete current proposal, including fifteen user stories and requirements.

I built the local workflows with React, Spring Boot/Security, signed JWT, BCrypt, Bean Validation, JPA, and four MySQL tables. History/admin lists use bounded pages. OpenAPI, measured Java coverage, exercised Postman, and actual SonarQube remain required evidence. See the [verification checklist](../03_Verification/01_Completion_Checklist.md).

AWS and related deployment/DevOps work are waived. Jira and branch protection are outside this pass. The 3D card is implemented on home, dashboard, and purchase pages with masked details and a reduced-motion fallback.
